# Dravidian Hate Speech Detection

Dravidian hate speech detection research code and dataset reference.

## Project Overview
This repository contains reference code for a Dravidian
hate speech detection research project.

## Dataset
The current experiments use a DravidianCodeMix-2020
dataset archive available to the project.

The original HASOC/FIRE 2021 dataset has been requested
from the research team for verification and further experiments.

## Purpose
This repository is shared to help the research team review
the implementation and provide guidance about dataset access.

## Main Files
- train_models_v3.py: Training script
- ensemble.py: Ensemble implementation
- evaluate_saved_models.py: Evaluation script
